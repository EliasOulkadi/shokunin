# README Forge

Generates READMEs that cover everything a new user needs. Standard structure, no frills, gets the job done.

## Structure

Project name with one-line description. Badges for CI, coverage, license, version. Table of Contents. Features 3-5. Installation. Quick Start. API Reference. Examples. Contributing. License.

## Quick Start Requirement

Copy-paste runnable. No omitted imports. No placeholders. The first example should be the first thing someone would try.

## API Reference Format

Each export gets: name, parameters table with type/required/default/description, return value with type and description, one example.

## Contributing

Fork, branch, commit, push, PR. Include dev setup, test command, lint command. Link to code of conduct.

## Anti-Patterns

Screenshots of code. Coming soon features. Missing prerequisites. No link to full documentation. Default README from template not customized.
