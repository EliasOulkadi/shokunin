Write marketing copy for landing pages, homepages, ads, and emails. Based on proven frameworks (AIDA, PAS, BAB, FAB) and conversion psychology research.

## Frameworks

| Framework | Structure | Best for |
|-----------|-----------|----------|
| AIDA | Attention -> Interest -> Desire -> Action | Landing pages, emails |
| PAS | Problem -> Agitate -> Solve | Sales pages, pain-point focused |
| BAB | Before -> After -> Bridge | Transformational offers |
| FAB | Feature -> Advantage -> Benefit | Product descriptions |
| 4Ps | Picture -> Promise -> Prove -> Push | Direct response |
| AICPBSAWN | Awareness -> Interest -> Comprehension -> Persuasion -> Bridge -> Scarcity -> Action -> Warn -> Now | Long-form landing pages |

## Structure

1. Headline: specific benefit, under 15 words, targets one reader
2. Subheadline: expands the promise, adds specificity
3. Opening: names the problem the reader has
4. Body: shows how your solution fixes it
5. Proof: testimonials, data, case studies
6. Objection handling: address the top 3 reasons they might not buy
7. CTA: one clear action, no ambiguity

## Tone Matrix

| Brand type | Voice | Vocabulary | Sentence length |
|------------|-------|------------|-----------------|
| Premium | Authoritative | Precise, confident | Medium (15-20 words) |
| Friendly | Warm, direct | Conversational, contractions | Short (10-15 words) |
| Technical | Precise, expert | Industry terms, data | Medium-long |
| Disruptive | Bold, challenging | Short, punchy, slang | Very short (5-10 words) |

## Anti-Patterns

| Mistake | Consequence | Fix |
|---------|-------------|-----|
| Generic headline | No one reads past it | Be specific: name the outcome + audience |
| Feature dumping | Reader does not connect to their life | Convert every feature to a benefit |
| Weak CTA | Low click-through rate | Use action verbs, specific outcome: "Start my free trial" not "Submit" |
| No social proof | Reader does not trust the claim | Add testimonials, numbers, logos near the ask |
| Writing for everyone | Resonates with no one | Define one reader. Write to them. |
| Hiding the CTA | Drop-off before conversion | Repeat CTA every 500 words on long pages |
