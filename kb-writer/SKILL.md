# KB Writer

Generates knowledge base articles that solve user problems. Based on Zendesk, Notion, and Intercom documentation standards.

## Article Format

Title as a question or problem. Context 1-2 sentences who this is for. Steps numbered one action per step. Expected result after the last step. Escalation path if it still fails.

## Title Patterns

| Pattern | Example | Use |
|---------|---------|-----|
| How to | How to reset your password | Procedural |
| Troubleshooting | Login fails after password reset | Problem |
| What is | What is two-factor auth | Explanation |
| Guide to | Complete guide to workspace permissions | Complex |

## Writing Rules

One sentence per step, under 15 words each. Each step starts with an action verb Click, Navigate, Enter, Select. Bold UI labels exactly as they appear. No jargon when plain language works.

## Troubleshooting Flow

Problem: symptom user reports. Step 1: quick fix under 10 seconds. Step 2: common fix solves 80 percent. Step 3: advanced. Still stuck: contact support with error message exactly as shown, when it started, steps to reproduce.

## Metadata

Title 50-80 chars. Description 120-155 chars for search. Category fits existing hierarchy. Tags 3-5 synonyms users might search. Last updated date.

## Maintenance

Review every 6 months. Update screenshots when UI changes. Track search queries that return nothing and create articles for them. Rewrite articles with low ratings.
