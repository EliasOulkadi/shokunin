## Executive Summary

```
[Client Name] needs to [solve specific problem].
We propose to [solution overview] over [timeline] for [price].
This achieves [key outcome 1], [key outcome 2], and [key outcome 3].
```

One paragraph. No more.

## Scope of Work

### Included
- Feature A (detailed description)
- Feature B
- 2 revision rounds
- Documentation

### Excluded (critical â€” prevents scope creep)
- Hosting and infrastructure
- Ongoing maintenance beyond warranty period
- Content creation
- Third-party licenses

### Assumptions
- Client provides access to existing systems within 3 days
- Decision maker available for weekly check-ins
- No changes to requirements during development

## Timeline Format

| Phase | Duration | Deliverable |
|-------|----------|-------------|
| Discovery | Week 1 | Requirements doc, wireframes |
| Build | Weeks 2-4 | Working implementation |

| Delivery | Week 6 | Handoff, docs |

## Risk Reduction

- Portfolio item similar to this project
- Case study with measurable results
- Testimonial from relevant client
- Guarantee (satisfaction, timeline, or money-back)
- References available on request
