# Código de Conducta

## Compromiso

Con el objetivo de fomentar un entorno abierto y acogedor, nos comprometemos a hacer de la participación en este proyecto una experiencia libre de acoso para todos.

## Estándares

**Comportamientos positivos:**
- Usar lenguaje acogedor e inclusivo
- Respetar puntos de vista distintos
- Aceptar críticas constructivas
- Enfocarse en lo que es mejor para la comunidad

**Comportamientos inaceptables:**
- Comentarios sexualizados o violencia
- Troleo, insultos y ataques personales
- Acoso público o privado
- Publicar información privada sin permiso

## Aplicación

Los mantenedores del proyecto se reservan el derecho de eliminar, editar o rechazar contribuciones que no sigan este código de conducta.
