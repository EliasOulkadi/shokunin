Write Twitter/X threads that stop the scroll and drive engagement. Based on analysis of 500+ viral threads and Twitter's algorithm mechanics (2024-2026) from Sahil Bloom, Matt Gray, Dickie Bush, and growth strategists.

## The Anatomy

```
Tweet 1: Hook — stop the scroll (240 chars max)
Tweet 2: Context — why this matters, what's at stake
Tweets 3-5: Value — the core teaching, step by step
Tweet 6: Proof — evidence, results, data, case study
Tweet 7: CTA — one clear action for the reader
```

7 tweets is optimal. Fewer than 5 = not enough value. More than 12 = drop-off.

## Hook Patterns

| Type | Formula | Example |
|------|---------|---------|
| Surprising stat | "[Number]% of [group] [do/are X]" | "90% of startups fail in the first year. Here's why the other 10% survive." |
| Contrarian | "I stopped doing [common thing]" | "I stopped writing unit tests. My code quality went up." |
| Direct promise | "[Number] [ways/lessons] to [outcome]" | "7 mental models that made me a better engineer" |
| Story opening | "I [did thing] and [unexpected result]" | "I rewrote one landing page and made $40K in 5 days." |
| Question | "Why do [group] keep [doing frustrating thing]?" | "Why do senior engineers keep saying 'it depends'?" |
| Bold claim | "Most [professionals] are wrong about [topic]" | "Most founders are wrong about pricing." |
| Relatable pain | "We all know [pain point]. Here's the fix." | "We all know the feeling of shipping a bug to production." |
| Insider | "Here's what nobody tells you about [topic]" | "Here's what nobody tells you about raising VC funding." |

First 5 words are the only ones that matter. If they don't hook in 5 words, the rest is invisible.

## Writing Rules

| Rule | Why |
|------|-----|
| One idea per tweet | If a tweet needs two ideas, it needs two tweets. Split it. |
| 240 chars max | Leave room for manual retweet with comment. Short tweets get more quote-retweets. |
| Line breaks inside tweets | Walls of text are skipped. 2-3 short lines per tweet. |
| No "I" or "Me" to start | Unless it's a personal story. Don't make it about you — make it about the reader. |
| No emojis in the first tweet | Unless they add clear meaning. Emojis in hook = looks like clickbait. |
| End every tweet with a reason to keep reading | Each tweet should make them want the next one. |
| Write conversationally | "You" and "your" more than "I", "we", "our". Reader is the hero. |
| Use specific numbers | "3.2x" not "more". "22 minutes" not "quick". |

## Value Delivery (Tweets 3-5)

Each value tweet teaches ONE thing. If the reader only reads tweets 3-5, they should still get value.

| Tweet | Content | Length |
|-------|---------|--------|
| Tweet 3 | The framework or mental model | 240 chars |
| Tweet 4 | How to apply it (step by step) | 240 chars |
| Tweet 5 | A real example with specifics | 240 chars |

Structure for each value tweet:
```
[Name the thing]: [1-line explanation]

How to do it:
→ [Step 1]
→ [Step 2]
→ [Step 3]

[Why this works / a pro tip]
```

## Proof (Tweet 6)

Tweet 6 is where you show you're not making it up. Types of proof ranked by effectiveness:

1. **Screenshot of results**: real dashboard, revenue graph, user count
2. **Data point with source**: "According to [source], [stat]"
3. **Case study**: "X tried this and got Y result"
4. **Your credentials**: "I've been doing this for N years. Here's what I learned."
5. **External validation**: "Retweeted by [authority]. Used by [company]. Featured in [publication]."

No proof means they'll assume you're theorizing.

## CTA (Tweet 7)

Never end with a question. End with a direction. Options:

- "RT the first tweet if this was useful" — highest reach driver
- "Follow me [@handle] for more" — growth focused
- "I wrote a full guide here: [link]" — traffic driven
- "Tag someone who needs this" — engagement driven
- "Bookmark this for later" — saves driven (signals the algorithm)

One CTA only. Don't ask them to do two things.

## Thread Structure Templates

### Educational Thread
```
Tweet 1: Hook — surprising truth or bold claim about [topic]
Tweet 2: "Here's why this matters to [audience]..."
Tweets 3-5: Numbered steps or principles (one per tweet)
Tweet 6: Personal story or proof that backs it up
Tweet 7: CTA + what they'll get if they follow
```

### Story Thread
```
Tweet 1: Hook — "I [achieved thing] by [doing unexpected thing]"
Tweet 2: "It started when [situation]..."
Tweets 3-4: "The problem was... So I tried..."
Tweet 5: "The breakthrough happened when..."
Tweet 6: "The result: [number/outcome]"
Tweet 7: "Key lesson + CTA"
```

### List Thread
```
Tweet 1: Hook — "[Number] [lessons/tools/tips] on [topic]"
Tweet 2: "#1: [name it, explain it]"
Tweet 3: "#2: [name it, explain it]"
Tweet 4: "#3: [name it, explain it]"
Tweet 5: "#4: [name it, explain it]"
Tweet 6: "#5: [name it, explain it]"
Tweet 7: "Which one resonates most? + CTA"
```

## Algorithm Considerations

| Factor | Impact | Strategy |
|--------|--------|----------|
| Saves | High | Make threads bookmark-worthy: actionable, specific, referenceable |
| Quote retweets | High | End with a provocative take or question to quote-reply to |
| Replies in first hour | Medium | Reply to your own thread to add context and engage commenters |
| Thread completion rate | Medium | Keep threads 5-8 tweets. Drop-off increases after tweet 8. |
| Image in thread | Medium | Include 1-2 screenshots or diagrams. Breaks up text. |
| Link in first tweet | Low (penalty) | Never link in tweet 1. Link in tweet 6-7 or replies. |
| Emoji use | Low | 1-2 total emojis per thread. 0 in the first tweet. |

## Engagement Response Strategy

| Comment type | How to respond |
|-------------|----------------|
| Agreement | "Appreciate that! What's your experience with [topic]?" |
| Question | Answer thoroughly. If good, turn into a future thread idea. |
| Disagreement | "Interesting take. Here's where I'm coming from..." — respectful disagreement generates engagement. |
| Adds value | "Great addition! [Restate + amplify their point]" |
| Criticism | "Fair point. Curious what specifically didn't land?" — engage, don't defend. |

Never ignore replies in the first 2 hours. The algorithm rewards engagement with the author.

## Anti-Patterns

| Mistake | Fix |
|---------|-----|
| 20-tweet threads | Nobody scrolls that far. Cut to 5-8. |
| Tweets that don't work standalone | Each tweet must make sense if it's the only one someone reads. |
| No line breaks | Walls of text get skipped. Use 2-3 line breaks per tweet. |
| Selling in the first 5 tweets | Build trust first. Sell in tweet 6-7 or replies. |
| CTA in tweet 20 | Nobody sees it. CTA in tweet 7. |
| Replying to your own thread for every tweet | Post as a thread, not replies. Algorithm treats replies differently. |
| No proof | "Trust me bro" doesn't work. Screenshots or data required. |
| Over-edited tone | Write like a human, not a brand. Imperfect is more engaging. |
| Too much text | 240 chars is a limit, not a target. 150-200 is often better. |
| No thread hook in bio | If the thread is good, pin it and update bio to mention it. |
