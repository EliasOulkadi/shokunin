# Twitter Thread

Generates threads that perform. Based on analysis of viral threads from Sahil Bloom, Matt Gray, Dickie Bush, and Twitter's algorithm mechanics (2025-2026).

## The Anatomy

```
Tweet 1: Hook — stop the scroll (240 chars max)
Tweet 2: Context — why this matters
Tweets 3-5: Value — the core, step by step
Tweet 6: Proof — evidence, example, data
Tweet 7: CTA — what to do next
```

## Hook Patterns

| Type | Formula | Example |
|------|---------|---------|
| Surprising stat | "[Number]% of [group] do [action]" | "90% of startups fail in year one" |
| Contrarian | "I stopped doing [common thing]" | "I stopped writing tests" |
| Direct | "[Number] ways to [solve problem]" | "5 ways to design better APIs" |
| Story | "I [did thing] and [unexpected result]" | "I built a startup in 30 days" |

First 5 words are the only ones that matter. If they don't hook, nothing else gets read.

## Writing Rules

- One idea per tweet. If it needs two, it needs two tweets.
- 240 chars max (leave room for manual RT with comment).
- Line breaks inside tweets for readability.
- No "I" or "Me" to start unless it's a personal story.
- No emojis in the first tweet (unless they add meaning).

## Value Delivery

Tweets 3-5 are where you deliver. Each tweet should teach one thing:
- Tweet 3: The framework
- Tweet 4: How to apply it
- Tweet 5: A real example

If the reader only reads tweets 3-5, they should still get value.

## Proof

Tweet 6 is where you show you're not making it up:
- A screenshot of results
- A data point with source
- A case study
- Your credentials (if relevant)

No proof means they'll assume you're theorizing.

## CTA

Never end with a question. End with a direction:

- "RT the first tweet if this was useful"
- "Follow me @handle for more"
- "I wrote a full guide: [link]"
- "Tag someone who needs this"

## Anti-Patterns

- 20-tweet threads (nobody scrolls that far)
- Tweets that don't work as standalone reads
- No line breaks (wall of text)
- Hiding the CTA in tweet 20
- Selling something in the first 5 tweets
